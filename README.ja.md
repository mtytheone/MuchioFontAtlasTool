# Muchio FontAtlasTool

> [English README is here](README.md)

ムチォの文字盤フォントを、好きなフォントに差し替えるための Unity エディタ拡張です。<br>
KAT (KillFrenzy Avatar Text) のタイル配置に準拠しています。
生成したテクスチャをマテリアルの `_MainTex` に差し替えるだけで、フォントが変わり、ついでに背景の黒帯も好みで消せます。

## 動作環境

> Unity 2022.3 以降

## インストール

### VCC（VRChat Creator Companion）から

1. 次のリンクを開き、**Add to VCC** でリスティングを追加します

   https://mtytheone.github.io/HatzeLaboratoryVpm/

2. VCC でプロジェクトの **Manage Project** を開き、`Muchio FontAtlasTool` の **+** を押します

### git URL から（VCC を使わない場合）

`Packages/manifest.json` の `dependencies` に追加：

```json
"com.hatzelaboratory.muchio.fontatlastool": "https://github.com/mtytheone/MuchioFontAtlasTool.git"
```

または Unity 上で **Window > Package Manager > + > Add package from git URL...**

## 使い方

1. 使いたい `.ttf` / `.otf` を Unity にインポートし、インポート設定の **Character** を **Dynamic** にする
2. **HatzeLaboratory > Muchio > Muchio FontAtlas Generator** を開く
3. フォントを割り当てた後、 **生成** を押す
4. 保存先を聞かれるので、場所と名前を決める

既定値はムチォ向けに調整済みなので、通常はフォントを指すだけで済みます。

### Basic Settings

| 項目 | 既定 | 意味 |
|---|---|---|
| フォント (ttf/otf) | 自動 | Dynamic なフォントのみ使用可 |
| フォントサイズ (px) | 240 | 元アトラスのキャップハイト168pxに合わせた値 |
| アウトライン (px) | 6 | 縁取りの太さ。アルファに焼き込まれ、`_ShadowColor` で着色される |
| **背景** | **透明** | **透明 = 背景を抜く。不透明 = 純正と同じ帯を出す** |
| 適用するマテリアル（任意） | なし | 指定すると生成後に `_MainTex` へ自動で差し込む |

### Advanced Settings

| 項目 | 既定 | 意味 |
|---|---|---|
| テクスチャ横／縦サイズ | 4096 × 8192 | 縦横の文字数で**割り切れる必要がある** |
| 横／縦に並べる文字数 | 16 × 16 | 256タイル |
| セル高比 | 0.67 | セル高さに対するベースライン位置 |
| オフセット X (px) | 0 | 字形の水平微調整 |
| タイル表 | ムチォ 互換 | 96〜101 に `っ ッ 　 、 ！ …` を含む並び |
| プレビュー文字 | `Aapあ゛` | プレビューに焼くサンプル文字 |
| 圧縮化 | OFF | ON にすると DXT5 でインポートする |

### 調整のコツ

- フォントによって字面率が違うので、プレビューを見て **フォントサイズを 220〜260 の範囲**で
  調整する。全角かながセル幅 256px を超えるようなら下げる
- `maxTextureSize` が 2048 なので、4096×8192 で焼いても実行時は 2048×4096 に縮小される。
  生成時間とメモリを詰めたいならテクスチャを 2048×4096・アウトライン 3 にすれば
  同じ結果で1/4になる（4096×8192 だと生成中に約128MB使う）
- `圧縮化` は既定 OFF。純正は DXT5 だが、6px の縁取りはアルファの段差が急なので
  ブロックノイズが出やすい。容量優先なら ON
- 収録文字の少ないフォントでは、`€`（95番）や `゛` `゜`（254/255番）、全角の `！` `…` が
  欠けることがある。**プレビュー文字にそれらを入れると、生成せずに有無を確認できる**
  （見つからない字形は生成時に Console へ警告が出る）

## アトラス仕様（実測値）

| 項目 | 値 |
|---|---|
| 画像サイズ | 4096 × 8192（実行時は maxTextureSize 2048 により 2048×4096） |
| グリッド | 16 × 16 = 256タイル、1セル 256 × 512 px |
| ベースライン | セル上端から 343px |
| キャップハイト | 168px（`A` `H` `1`）／全角かなの高さ 約200px |
| 水平位置 | 字送り幅基準でセル中央にセンタリング |
| RGB | 白の字形のみ（背景は黒） |
| Alpha | 字形を約6px膨張させた領域 = 255、それ以外 = 0（または帯の値） |
| インポート設定 | ミップマップ無効 / sRGB / Clamp / Bilinear / maxTextureSize 2048 |

縁取りはチャンファ距離変換で作っているため、正方形やひし形ではなく丸く出ます。

### タイルの並び

- **0〜94** … ASCII 32〜126（`index = 文字コード - 32`）
- **95** … `€`
- **96〜101** … `っ ッ 　 、 ！ …`（ムチォ互換。KAT 本家では空き）
- **127** … `ぬ`（128 も空き）
- **129〜255** … JISかな配列の並び（`ふあうえおやゆよわをほへたてい` → `すかんなにらせちとしはきくまのり` → …）、254/255 が `゛` `゜`

ひらがな部分がJISかな配列順なのは、OSC側アプリがキー位置からタイル番号を引くためです。

> **この並びを変えると文字が化けます。** フォントだけ差し替える限りは触らないでください。

「KAT 本家準拠」ボタンで 96〜101 を空にした並びにも切り替えられますが、VRCPet で使う場合は
これらのタイルが必要なので、既定の「ムチォ 互換」のままにしてください。
